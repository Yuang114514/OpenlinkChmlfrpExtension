# 开放式联机：Chmlfrp 扩展
一个为Chmlfrp开发的OpenLink附属
### 基于OpenLink的Frpc接口
[看看OpenLink项目](https://github.com/StarCarefree/OpenLink)
[看看Frpc文档](https://terry-mc.top/javadoc/fun/moystudio/openlink/frpc/package-summary.html)

### 特性

- 登录与登出
- 敏感信息存储在Preference中，不会放到游戏目录
- 自动的隧道资源管理
- Frpc管理

### 下载

- 在[Actions Page](https://github.com/Yuang114514/OpenlinkChmlfrpExtension/actions)可下载最新文件
- 在[Modrinth](https://modrinth.com/mod/openlink-chmlfrp-extension)和[Curseforge](https://www.curseforge.com/minecraft/mc-mods/openlink-chmlfrp-extension)可下载发行版
- 在[mc百科](https://www.mcmod.cn/class/25188.html)可查看简介
